# 微信小程序预留

Stage 00+01 仅创建本说明，不生成 uni-app 工程，不创建 package.json，不安装或构建小程序依赖。

后续技术方向：**uni-app + Vue 3 + TypeScript**。小程序拥有独立页面实现、依赖、构建及微信发布流程；PC 继续继承现有 `web/` JavaScript 工程。小程序需经微信开发者工具及相应体验/发布流程验证，PC 构建不能替代小程序验收。

一期移动端优先严格依据原需求清单的 5 条：AI随手拍 4 条由 B 负责，工单处理 1 条由 A 负责。本阶段不另拟 5 条的具体功能定义、不扩展其他模块的移动端范围。后续实施前应核对原需求逐条映射。

PC 与移动端共用业务字段、状态定义和数据协议，页面实现独立；共同定义在后续确认的 `contracts/` 内维护。本阶段尚无正式接口或状态机，也不宣称跨端数据同步可用。

模块归属、公共文件修改和 Git 工作方式遵守 [OWNERSHIP](../docs/collaboration/OWNERSHIP.md)。后续小程序公共骨架和配置由 A 协调，模块实现归对应负责人；必须在另行授权的阶段创建。
